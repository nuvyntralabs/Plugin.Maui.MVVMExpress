# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in MVVMExpress a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity, experience, education, socio-economic status, nationality, appearance, race, religion, or sexual identity and orientation.

## Enforcement

Report unacceptable behavior to the maintainers via GitHub Security Advisories or the contact listed in [SECURITY.md](SECURITY.md). Maintainers will review and respond as appropriate.

This code of conduct applies to all project spaces, including issues, pull requests, and discussions.
