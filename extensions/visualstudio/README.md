# MVVMExpress for Visual Studio

Thin VSIX (VS 2022 17.0+). Install from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/search?term=MVVMExpress&target=VS&category=All%20categories&vsVersion=&sortBy=Relevance) (search **MVVMExpress**). On first use it installs `Plugin.Maui.MVVMExpress.Templates` and runs `dotnet new`. The **IDE extensions** workflow uploads the `.vsix` artifact. See [extensions/README.md](../README.md).
