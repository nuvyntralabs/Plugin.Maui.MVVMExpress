# MVVMExpress for Visual Studio Code

Thin wrapper around `Plugin.Maui.MVVMExpress.Templates`. It does not copy the scaffold; it installs the template pack and runs `dotnet new`.

Install from the [Visual Studio Code Marketplace](https://marketplace.visualstudio.com/search?term=MVVMExpress&target=VSCode&category=All%20categories&sortBy=Relevance) (search **MVVMExpress**).

## Commands

- **MVVMExpress: Create New App** — folder + name → `dotnet new mvvmexpress`
- **MVVMExpress: Add Page** — name + namespace → `dotnet new mvvmexpress-page`

Requires the .NET SDK on PATH. Product docs: [extensions/README.md](../README.md).
