# MauiApp1

Generated by `dotnet new mvvmexpress`.

```bash
dotnet test MauiApp1.Tests
dotnet build MauiApp1/MauiApp1.csproj
```

- **MainPage** / **MainPageViewModel** — XAML page, `[Notify]`, `IncrementCommand`, `IGreetingService` via `AddMain()`, `{Binding}` and `Command`
- **Login** → `ResetAsync<MainPageViewModel>` so Back cannot return to the sign-in page
- **Items** — list (`CollectionView` + `SnapshotCollection`) and form (`FormViewModel.Field` + `Bind`)
- **Tests** run on `net10.0` without a device

Add another page:

```bash
dotnet new mvvmexpress-page -n Catalog --namespace MauiApp1
```

Demo credentials: `demo@mvvmexpress.dev` / `secret`. Replace `DemoAuthState` with [Plugin.Maui.SecureSession](https://www.nuget.org/packages/Plugin.Maui.SecureSession) before shipping.
